Privacy Policy — Zlatan Assistant

Zlatan Assistant is a personal assistant used only by its owner. It is not offered to other users.

Data accessed

With the owner's consent the app accesses the owner's Gmail messages (read and send) and Google Calendar events (read, create, delete) via Google APIs.

How data is used

Data is used only to answer the owner's own requests in a private chat with the assistant. Sending email and changing the calendar happen only after the owner explicitly confirms each action.

Sharing and storage

Google user data is not sold, not shared with third parties, and not used for advertising. To produce answers, the content needed for a request is processed by the AI model provider (Anthropic). Access tokens are stored only on the owner's private server.

Revoking access

The owner can revoke access at any time at myaccount.google.com/permissions.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
